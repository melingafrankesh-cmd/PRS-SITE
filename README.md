# PRS : site web de l'entreprise

Site web de **PRS**, entreprise de technologie et d'informatique spécialisée dans la **vente, l'échange, le développement et la réparation** d'équipements informatiques.

Projet réalisé par **[Frankesh MELINGA]**, L2 Génie informatique, **[IUT FV]**, année **2026**.

## Public visé
- Entreprises du secteur informatique
- Étudiants en informatique
- Tous les secteurs technologiques

## Pages
| Page | Fichier | Contenu |
|------|---------|---------|
| Accueil | `index.html` | Bannière, services, public visé, chiffres clés |
| À propos | `a-propos.html` | Histoire, mission, valeurs, équipe |
| Services | `services.html` | Détail des 4 services, étapes de travail |
| Catalogue | `catalogue.html` | Produits filtrables par catégorie, avec recherche |
| Contact | `contact.html` | Formulaire validé, coordonnées, horaires |

## Technologies
- HTML5, CSS3 (Flexbox, Grid, variables CSS, responsive)
- JavaScript (menu mobile, compteurs animés, filtres et recherche, validation de formulaire)
- Polices Google Fonts : Space Grotesk, Inter, JetBrains Mono

## Lancer le projet
1. Télécharger ou cloner le dépôt
2. Ouvrir le dossier dans VS Code
3. Clic droit sur `index.html` → **Open with Live Server** (ou ouvrir `index.html` dans un navigateur)

## Fonctionnalités JavaScript
- **Menu burger** adaptatif sur mobile
- **Compteurs animés** déclenchés au défilement
- **Catalogue dynamique** : filtre par catégorie et recherche en direct
- **Formulaire de contact** : validation des champs et ouverture de la messagerie avec le message prérempli

## Charte graphique
- Couleurs : bleu nuit `#0B1220`, bleu `#2563EB`, cyan `#22D3EE`, gris clair `#F1F5F9`
- Logo : puce électronique avec le symbole `</>` et les initiales PRS
